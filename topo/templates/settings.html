Default credentials
loading
Used by every device without its own credentials. Per field, a device's own value wins, then this page, then the TOPO_SSH_* / TOPO_SNMP_* environment. A blank secret field keeps the stored value. Stored in plaintext in topo.db.
Syslog from other servers
loading
Lets a device log to one Confetti server only. This server then reads the other one's own messages every few seconds (nothing it pulled itself is passed on) and skips a message it already has. Switching a server on starts from its newest message; its history is not copied. Set its URL in the section above first. A pulled message from a device here also asks for an early poll.
Other Confetti projects
A small button for each URL that is filled in appears at the right of the top menu on every page and opens that project in a new tab. Only http:// or https://. Leave a field empty to remove its button. The server connects to one of these addresses only for the syslog pull below, and only if you switch that on.
LLDP neighbor matching
loading

Only for a neighbor that advertises no management IP a known device owns. A match is used only when exactly one device has the MAC or name, and is not saved as an identity. Two devices with the same name, or a reused MAC, are left unmatched. A device reports its own MAC only on PAN-OS (poll it once); name matching works for any device. Off by default.
Flapping on Recent changes
A peer, interface or port that changed this many times within this many minutes gets a "flapping" mark on the Recent changes page. Display only: nothing is stored or alerted. Default 3 changes within 60 minutes.
Backup and restore
A backup is the whole database: devices, history, templates, settings and the device credentials in plaintext. Keep the file private. On the VM, topo-db.sh does the same from the shell.
